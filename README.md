# JheyDev ART — Portfólio

Projeto estático em HTML, CSS e JavaScript, responsivo para desktop, tablet e celular.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Para desenvolvimento local, você também pode abrir a pasta no VS Code e usar a extensão Live Server.

## Estrutura
- `index.html` — conteúdo e estrutura das seções.
- `styles.css` — identidade visual, layout e responsividade.
- `script.js` — menu mobile, navegação ativa, filtros de projetos e botão voltar ao topo.
- `assets/mascote-jheydev.png` — mascote ilustrada.
- `assets/referencia-visual.png` — referência visual do protótipo.

## Antes de publicar
Personalize:
- O e-mail `contato@jheydev.art` no `index.html`.
- Os links de LinkedIn, GitHub e Instagram (os links estão como `#` inicialmente).
- Os cards demonstrativos da seção Portfólio com seus projetos reais, capturas de tela, descrições e links.
- O texto de apresentação e a lista de competências conforme sua experiência atual.

As fontes Nunito e Space Grotesk são carregadas do Google Fonts; se estiver offline, o site usa fontes de sistema como alternativa.
